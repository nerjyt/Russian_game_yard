ТЕКСТУРЫ ДЛЯ «ДВОРА»
====================

Игра сама подхватит файлы из этой папки. Ничего в коде менять не надо.
Нет файла — рисуется процедурная текстура, как сейчас. Есть — берётся твоя.

ГДЕ БРАТЬ (обе лицензии CC0: коммерция разрешена, указывать автора не обязательно)
  ambientCG   https://ambientcg.com
  Poly Haven  https://polyhaven.com

Качай 2K, формат PNG или JPG. 4K не нужен — сожрёт память без разницы в картинке.

ИМЕНА ФАЙЛОВ — СТРОГО ТАКИЕ
---------------------------
Для каждой поверхности нужен хотя бы <имя>_color.
Если есть карта нормалей — клади <имя>_normal, картинка станет объёмной.

  panel_a, panel_b, asphalt, grass

КАК ПРОВЕРИТЬ
-------------
Положил файлы → Unity сам их импортирует → Play.
В консоли появятся строки вида:
  [Двор] Материал «asphalt» взят из файла (с картой нормалей)
Если строки нет — не совпало имя файла. Проверь: всё маленькими буквами,
без пробелов, окончание ровно _color или _normal.

Настройки импорта проставляются сами: карты нормалей помечаются как NormalMap,
повтор, анизотропия, мипмапы. Руками ничего выставлять не нужно.
